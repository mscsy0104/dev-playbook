# 공통 검사 가이드

| 파일 | 내용 |
|---|---|
| `00_검사_개요.md` | 검사 5가지, 실행 순서, 검사 → 모듈 표, 결과를 보는 곳 |
| `01_단위_테스트.md` | 단위 · 통합 테스트: 층, 설정, 폴더 구성, 테스트 대상 표, 실행 방법, 결과 읽기, 실행 시점 |
| `02_정적_검사.md` | import 규칙 검사 · 린터 · 정적 타입 검사: 설정, 계약 종류, 자주 보이는 지적과 고치는 법, 실행 시점 |
| `03_런타임_검사.md` | 서비스가 기동 때 · 실행 중에 하는 검사 목록, 확인 방법, 거부 코드 → HTTP 상태 표 |
| `04_실측_검사.md` | 실제 외부 서비스 전체 처리: 확인 항목과 통과 기준, 기준값 표, 로컬 · 원격 절차 |
| `05_스모크_검사.md` | 새 컨테이너 이미지 스모크 검사: 이미지에서만 생기는 문제, 최소 확인 목록, 테스트 · 손 실행, 결과 기록, 실패 대응 |

새 프로젝트에 쓰려면 이 폴더를 프로젝트의 검사 안내 폴더로 복사하고, 각 문서의 "프로젝트마다 채운다" 표와 아래 "프로젝트마다 한 번 채우는 값" 표의 자리표시를 프로젝트 값으로 바꾼다.

## 자리표시

### 프로젝트마다 한 번 채우는 값

폴더 · 파일 자리표시는 저장소 루트 기준 경로다.

| 자리표시 | 뜻 | 예 |
|---|---|---|
| `<repo>` | 메인 저장소 절대경로 | `/Users/me/projects/order_service` |
| `<규칙 폴더>` | 공통 규칙 문서(`코드_규칙.md` 등)를 둔 폴더 | `docs/claude_inst/rules` |
| `<검사 안내 폴더>` | 이 검사 안내 문서들을 둔 폴더 | `docs/guides` |
| `<실행 기록 폴더>` | 실제 외부 서비스 실행 · 스모크 결과를 남기는 폴더 | `samples/runs` |
| `<공통 fixture 파일>` | 테스트 층마다 공통 fixture를 두는 파일 | `tests/conftest.py` |
| `<결과 행 검사 도우미>` · `<상태 파일 읽기 도우미>` · `<결과 파일 검사 도우미>` · `<외부 연동 판단 도우미>` | 테스트 층 사이 공통 도우미 파일 | `tests/result_files.py` |
| `<결과 행 파일>` | 작업 폴더의 항목별 결과 행 파일 이름 | `orders.csv` |
| `<설정 파일>` | 서버가 읽는 설정 파일 이름 | `sources.yaml` |
| `<이미지>` | 컨테이너 이미지 이름 | `order_service` |
| `<서비스>` | compose 서비스 이름 | `app` |
| `<컨테이너 데이터 경로>` | 컨테이너 안 데이터 · 설정 마운트 경로 | `/srv/app` |
| `<ROOT>` | 서버 저장 루트 | `/srv/app/data` |

### 실행 · 명령마다 채우는 값

| 자리표시 | 뜻 | 예 |
|---|---|---|
| `<티켓>` | 티켓 번호 | `ABC-123` |
| `<날짜>` · `<YYYY-MM-DD>` | 실행 날짜 | `2030-01-15` |
| `<대상>` | 처리 대상(외부 서비스) 이름 | `payments` |
| `<작업 id>` · `<execution_id>` | 접수 응답의 작업 id | 접수 응답의 `execution_id` 값 |
| `<worktree 또는 저장소 루트>` | 명령을 실행하는 폴더 | `<repo>` |
| `<테스트 파일>` · `<테스트 파일들>` · `<파일>` | 실행 · 수정할 테스트 파일 | `tests/unit/test_dates.py` |
| `<패키지>` | 오류 메시지에 나오는 패키지 이름 | `order_service` |
