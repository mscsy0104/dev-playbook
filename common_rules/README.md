새 프로젝트에 쓰려면 이 폴더를 프로젝트의 규칙 폴더로 복사하고, 아래 "프로젝트마다 한 번 채우는 값" 표의 자리표시와 `코드_규칙.md`의 계층 그림을 프로젝트 값으로 바꾼다.

## 자리표시

### 프로젝트마다 한 번 채우는 값

폴더 · 파일 자리표시는 저장소 루트 기준 경로다. 명령 안에서는 `$R/<작업 큐 폴더>`처럼 저장소 루트 뒤에 붙여 쓴다.

| 자리표시 | 뜻 | 예 |
|---|---|---|
| `<repo>` | 메인 저장소 절대경로 | `/Users/me/projects/order_service` |
| `<base branch>` | 작업 브랜치를 만드는 기준 브랜치 | `develop` |
| `<문서 폴더>` | 세션 문서를 두는 폴더. gitignore로 두면 worktree에 없다 | `docs` |
| `<진행 상태 파일>` | 브랜치 · 미뤄 둔 작업 · 세션 작업판 · 사용자 결정 대기를 둔 파일 | `docs/claude_inst/status.md` |
| `<작업 큐 폴더>` | 지시 문서 · 결과 문서를 두는 폴더 | `docs/claude_inst/active_works` |
| `<규칙 폴더>` | 이 규칙 문서들을 둔 폴더 | `docs/claude_inst/rules` |
| `<리뷰 기준 파일>` | 리뷰에서 나온 공통 기준을 번호로 쌓는 파일 | `docs/claude_inst/리뷰_반영_포인트.md` |
| `<설계서 폴더>` | 설계서 작업본과 `CHANGELOG.md`를 둔 폴더 | `docs/claude_inst/design` |
| `<결정 기록 폴더>` | 티켓별 결정 기록(ADR) 폴더 | `docs/claude_inst/decisions` |
| `<표현 변경 기록 폴더>` | 리뷰 문답과 바꾼 표현 표를 두는 폴더 | `docs/review` |
| `<회고 폴더>` | 티켓별 회고 폴더 | `docs/retro` |
| `<개념 문서 폴더>` | 티켓별 개념 설명 폴더 | `docs/concepts` |
| `<조사 문서 폴더>` | 조사 · 실측 문서 폴더 | `docs/inv` |
| `<질의응답 폴더>` | 질의응답 문서 폴더 | `docs/qna` |
| `<정리 문서 폴더>` | 정리 · 검토 · 할 일 목록 폴더 | `docs/etc` |
| `<미뤄 둔 작업 폴더>` | 미뤄 둔 작업 문서 폴더 | `docs/future` |
| `<spec 폴더>` · `<plan 폴더>` | 티켓별 설계 · 구현 계획 폴더 | `docs/superpowers/specs` · `docs/superpowers/plans` |
| `<모듈 지도 파일>` | 소스 모듈 표 파일 | `docs/모듈_지도.md` |
| `<용어집 파일>` | 개발 · 도메인 용어집이 있는 파일 | `README.md` |
| `<실행 기록 폴더>` | 실제 외부 서비스 실행 · 스모크 결과를 남기는 폴더 | `samples/runs` |
| `<최상위 패키지>` | 소스의 최상위 패키지 이름(부록의 import 규칙 계약) | `order_service` |

### 작업 · 명령마다 채우는 값

| 자리표시 | 뜻 | 예 |
|---|---|---|
| `<티켓>` | 티켓 번호 | `ABC-123` |
| `<slug>` | 브랜치 · worktree 이름에 붙는 짧은 설명 | `storage-interface` |
| `<branch>` | 작업 브랜치 | `feature/ABC-123/storage-interface` |
| `<worktree>` | worktree 폴더 이름 | `ABC-123-storage-interface` |
| `<역할>` · `<session>` | 세션 역할 · 세션 이름(`<역할>-<티켓>`) | `coding` · `coding-ABC-123` |
| `<지시 문서>` · `<지시 문서 경로>` | 세션에 주는 지시 문서 이름 · 경로 | `20300115-0930_coding-ABC-123_instruction.md` |
| `<path>` | 결과 문서 경로 | `<작업 큐 폴더>/20300115-1000_coding-ABC-123_result.md` |
| `<surface ref>` · `<자기 surface ref>` · `<coding의 surface ref>` · `<ref>` · `<main>` | cmux 받는 쪽 · 자기 · coding 세션 · 워크스페이스 · main의 ref(`CMUX_QUIET=1 cmux tree`로 확인) | `surface:12` |
| `<메시지 id>` | 답할 cmux 메시지 id | `cmux agent inbox` 출력의 id |
| `<내용>` | 보낼 메시지 본문 | `result saved: …` |
| `<주제>` | 개념 문서 주제 | `저장소_인터페이스` |
| `<날짜>` | 실행 날짜 | `2030-01-15` |
| `<대상>` | 실행 · 스모크 대상 이름 | `payments` |
| `<규칙>` | 무시 주석에 적는 린터 · 타입 검사 규칙 이름 | `BLE001` |
| `<예외 클래스>` | 런타임에 만드는 코드 값에 들어가는 예외 클래스 이름 | `TimeoutError` |
| `<패키지>` | 오류 메시지에 나오는 패키지 이름 | `order_service` |
